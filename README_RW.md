# MIAC Youth Skills App

## Gutangiza
1. Shyira Node.js kuri mudasobwa niba itarimo.
2. Fungura iyi folder muri VS Code.
3. Muri terminal, koresha `npm install`.
4. Hanyuma ukoreshe `npm run dev`.
5. Fungura URL Vite ikwereka, akenshi `http://localhost:5173`.

## Ifoto ya logo
Shyira ifoto yawe muri `public/images/` uyite `student.jpg`.

## Icyitonderwa
Login na Register ni demo gusa. Nta database, secure authentication, email delivery cyangwa course progress persistence bihari. Ntukoreshe demo login mu makuru y'ibanga cyangwa konti z'ukuri. Kugira ngo ibe production app, hakenewe backend/database n'umutekano.
